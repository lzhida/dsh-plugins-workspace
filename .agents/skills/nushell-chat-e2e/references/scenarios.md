# 12 类场景定义与硬校验期望值

`<BASE_DIR>` = 系统临时目录下的独占目录（如 `/tmp/dsh-shell-e2e-<日期>`，**命名不得含 "nushell"——该路径会出现在对话文本里**），发送对话前替换为实际路径。

| # | 场景 | 操作 | 硬校验期望值 |
| --- | --- | --- | --- |
| 1 | 基础文件操作 | `<BASE_DIR>/fs` 下建 `hello.txt` 写 `e2e-ok` → 重命名 `hello-renamed.txt` → 读回 → 删除 | 读回内容 = `e2e-ok`；删除后再读取报「文件不存在」类错误 |
| 2 | 目录浏览与过滤排序 | `<BASE_DIR>/sort` 下建 `a.txt`(3 字节)、`bb.txt`(200 字节)、`c.md`(50 字节)；按大小降序 + 只留 `.txt` | 结果恰好为 `bb.txt`、`a.txt` 且该顺序；`c.md` 不出现 |
| 3 | 结构化数据解析 | 写 `<BASE_DIR>/data/team.json`：`{"team":[{"name":"alice","score":90},{"name":"bob","score":70}]}` 提取字段；另写 `rows.csv`（表头 + 2 数据行）统计 | 姓名序列含 `alice`、`bob`；JSON 记录数 = 2；CSV 数据行数 = 2 |
| 4 | 系统信息查询 | 当前用户名、`PATH` 环境变量存在性、进程列表 | 用户名非空；PATH 存在；进程表行数 ≥ 1 且为结构化表 |
| 5 | 外部命令调用 | 执行 `git --version`（外部命令语法） | 输出匹配 `git version <数字>` |
| 6 | 错误处理 | 读取 `<BASE_DIR>/nonexistent.txt` | 返回明确错误信息（如 Not found / 找不到文件），会话不崩溃，后续命令仍可执行 |
| 7 | 管道数据链 | `1..10` 管道求和 + 求平均 | **和 = 55**；平均 = 5.5 |
| 8 | 数据格式转换 | `{"a":1,"b":"x"}`：JSON → YAML → 转回 JSON | YAML 文本含 `a: 1`；转回后 `a == 1` |
| 9 | 字符串插值与处理 | 插值 `e2e-(6 * 7)`；`Hello World` 转小写；`a,b,c` 按逗号拆分 | 插值结果 = `e2e-42`；小写 = `hello world`；拆分得到 3 个元素 |
| 10 | 日期时间 | 当前日期格式化取年份；`date now` 减 `2026-01-01` | 年份 = 执行日所在年份（模板生成时按当日更新）；时长为正值 |
| 11 | 自定义命令 | `def add-two [x: int] { $x + 2 }` 后调用 `add-two 40` | **结果 = 42** |
| 12 | 写出回读 | `[[a, b]; [1, 2]]` 保存 `<BASE_DIR>/out/table.json` 再读回 | 读回 `a == 1` 且 `b == 2` |

## 出题意图（覆盖面说明）

- 1/2/5/6：通用 shell 高频操作与异常路径
- 3/7/8/9/11/12：结构化管道、格式转换、闭包/插值、自定义命令——区别于 POSIX shell 的核心特性
- 4/10：环境与时间等系统能力

## 实测语义注记（nu 0.115.1，2026-09-22）

- 场景 2：`'x' * 200` 字符串重复运算符**不支持**——首跑在此失败属预期，标准解法 `1..200 | each {|_| 'x'} | str join`；审查时命令改写不算失败
- 场景 9：`str downcase` 自 0.114 起弃用（建议 `str lowercase`），结果正确即通过；注记供命令审查参考
- 前置依赖：本机必须已装 `nu` 且在 dsh 进程 PATH 内（实测 `~/.local/bin/nu` 即可，执行器 spawn 时解析，无需重启 dsh）；缺失时报 `spawn nu ENOENT`，goal 第 1 轮即全部失败并如实报告（这本身是有效的失败路径测试样本）

## 期望值维护

- 场景 10 的年份按测试执行日更新
