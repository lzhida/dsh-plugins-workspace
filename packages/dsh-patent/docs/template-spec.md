# 交底书模板规格（disclosure-template.docx）

内置模板来自用户提供的公司模板，已做去公司化处理（申请人字段的值替换为占位
「〔申请人：请填写公司名称〕」，其余格式原样保留）。本文件是模板的结构规格，
供模型在填充 / 重建模板时对照。

## 头部字段（正文段落，非表格）

| 字段       | 原文形态                                                                | 填充目标                                                              |
| ---------- | ----------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 标题       | `专利技术交底书`                                                        | 不变                                                                  |
| 案件名称行 | `专利申请案件名称：___ 申请类型 发明 实用新型 内部案号`                 | 案件名称填入下划线区；申请类型在「发明/实用新型」中选定；内部案号填入 |
| 申请人行   | `申请人： 〔申请人：请填写公司名称〕 发明人：`                          | 申请人：config 默认或占位；发明人：填入                               |
| 联系人行   | `技术问题联系人：___ 联系人电话：`                                      | 联系人、电话                                                          |
| 邮箱行     | `联系人邮箱：`                                                          | 邮箱                                                                  |
| 公开情况行 | `已公开或即将公开发表与本技术相关的资料（期刊、论文、宣传册等）：是 否` | 在「是/否」上选定                                                     |

## 七个部分

一~六为「标题段落 + 单格内容表格」结构（`doc.tables[0..5]` 依次对应）；七为纯说明段落。

### 一、背景技术（tables[0]）

原提示：做这项改进之前技术现状的详细描述，可以用文字描述（比如改进之前的化学成分、加工工艺、数据处理过程等），也可以结合附图进行详细说明（比如改进之前的机械结构或电路构造）。如果为全新的产品或工艺，可以介绍一下相关的产品或工艺，比如发明了汽车，可以介绍一下自行车等。

### 二、背景技术的技术问题（tables[1]）

原提示：（指出背景技术在哪些地方存在哪些缺陷和不足：如成本高、效率低、结构复杂、速度慢、体积大、污染量大、能耗高等）。
1.最主要、最关键的技术问题：
2.次要问题（如果有多个，可以依次列出）：

### 三、本案的详细阐述（tables[2]，重点）

原提示：（本部分为重点内容，需要对发明创造进行详细、完整的公开，完整公开的标准为同领域的技术人员看过本部分的描述就能够明白是如何实施才能解决上面的问题的。）

### 四、第三项的技术方案中有无可以替代的地方（tables[3]）

原提示：（比如有些部件、工艺可以用别的部件、工艺替代；有的部件可以省略，同样可以解决背景技术的问题等）（此部分可不填，填了则更好）

### 五、第三项的技术手段产生了什么技术效果（tables[4]）

原提示：（通常为克服了第二项所指出的技术问题，比如速度快、体积小、能耗低等）。

### 六、本案需要保护的要点（tables[5]）

原提示：（此部分可不填，填了则更好）

### 七、附图要求（说明段落，无表格）

- 产品类发明或实用新型要有附图，只能采用 A4 大小的图纸。
- 申请机械产品附图要求为 AUTOCAD 格式的立体轮廓线图，可以结合剖面图、爆炸图等体现发明的特征。图上主要零部件需标注序号，并注明该序号对应的名称。
- 申请电子类产品或机电相结合的产品必须提供主要的电路图，如果一张 A4 大小的图纸难以表述，可采用分块表示的形式，或先画出电路原理框图，另外再分别提供详细的电路图。

## 填充规则（python-docx）

1. `Document(模板路径)` 打开；
2. 头部：按上表在段落 run 内替换值区文本（保持 run 格式；占位符「〔…〕」整段替换）；
3. 一~六：`doc.tables[0..5]` 的 `rows[0].cells[0]`，清掉灰字提示段落后写入正文
   （多段落用 `cell.add_paragraph` 追加，保留首个段落样式）；
4. `doc.save(目标路径)` 另存 workspace。

公司信息默认值从插件设置读取（dsh-patent 的 disclosureDefaults）；未配置时保留
占位并提醒用户自行修改。
