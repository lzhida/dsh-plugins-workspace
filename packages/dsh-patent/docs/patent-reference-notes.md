# 中国专利公布文本撰写参考语料（6 份样本提炼）

来源：用户提供 的 6 份 CNIPA 公布/授权文本（CN122310513A/B、CN115996222A/B、
CN121967546A、CN122021493A）的逐页视觉分析结论。用途：撰写交底书时参考公开
专利文本的结构与措辞；权利要求式表述（保护要点）的宽容校验依据。原件不入库。

## 结构（电子公布文本形态）

固定顺序：扉页（含 (57) 摘要与摘要附图）→ 权利要求书 → 说明书 → 说明书附图。
**没有独立的"说明书摘要"页**——摘要只印在扉页 (57) 栏。

授权版（B）扉页差异：(45) 授权公告日、(65) 已公布文献号、(73) 专利权人（替代
(71) 申请人）、(56) 对比文件 + 审查员。

## 页码双轨

- 页眉：左公布号｜中部分名（"权 利 要 求 书"字间空格式）｜右 "N/M 页"（部分内页码）
- 页脚：全文连续页码，扉页 = 1（自身不印），权利要求书从 2 起接续

## 段号与编号

- 说明书段号：**`[0001]` 半角方括号 + 4 位零填充**，跨小节连续到文末；粒度跟随
  自然段（可单句一段，步骤行可不带新段号）
- 权利要求编号：`1.` 阿拉伯数字+点（未见顿号式）
- 摘要：单段无段号，约 230-320 字（与 ≤300 字规范一致）

## 权利要求引用句式（真实变体，校验需宽容）

- 主干："根据权利要求N所述的……，其特征在于……"（后接逗号或冒号均见）
- 多引范围："权利要求1至8中任一项" 与 "权利要求1-3任一" 并存
- 引用名称带不带"一种"不统一
- 独权开头多数 "1.一种……"，但存在无"一种"的写法（如"1.基于C#的…方法"）
- 方法步骤编号三种并存：（1）（2）／ 步骤S1、／ S1、命名式
- 多类型组合顺序多样：方法→系统→介质；平台→方法→设备→介质
- 设备权句式含"实现**根据**权利要求X至Y中任一项所述的方法"
- 介质权三种变体：计算机程序被处理器执行时实现 / 计算机指令…使得…执行

## 措辞套路（写交底书可借鉴）

- 发明内容组织："第一方面，本发明提供了一种……"（方法/平台）、"第二方面"（系统）、
  "第三方面"（介质）；"进一步地，"引导从属方案；"本发明具备的有益效果是："
- 附图说明：逐图独立段，"图N是……的流程示意图/示意图/框架示意图；"（末图句号）
- 背景技术引证："申请公布号为CN102929756A的中国专利，公开了……"
- 说明书尾部声明："以上所述的实施例只是本发明的较佳的方案，然其并非用以限制本
  发明。……均落在本发明的保护范围内。"
- "所述"使用密度极高（术语前几乎必加）

## A/B 修改模式（公开 → 授权）

- 权利要求合并收紧：部分从权内容并入独权（独权变长）、剩余从权重编号且引用
  基准统一改为直接引用权 1、介质权引用范围跟随新编号
- 说明书、附图、发明名称、摘要逐字不变；总页数变化仅来自权利要求书

## 对校验工具的指引

权利要求编号按 `\d+\.`；段号按 `\[\d{4}\]`；引用句式宽松匹配
（"至|-"、"中任一项|任一"、引用带不带"一种"）；不对"其特征在于"后标点做硬校验。

## 专利数据库检索接入（2026-11-20 调研定稿）

背景技术引证要落到「申请公布号为CN…A的中国专利，公开了……」，检索与字段口径：

### 各数据源可用性

| 数据源                                | 可用面                                                                                     | 凭据                                                                                        | 覆盖                   | 结论                                                              |
| ------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- | ---------------------- | ----------------------------------------------------------------- |
| CNIPA                                 | 无公开 REST/JSON/XML 接口；主站 JS SPA + WAF/CAPTCHA；批量数据为付费产品                   | —                                                                                           | CN                     | 不可直连，境外访问受限；中国专利走 EPO OPS / PATENTSCOPE 间接取数 |
| 国家知识产权运营公共服务平台（sipop） | `patentBase.queryBasicInfo` 等著录接口                                                     | appKey + MD5 sign，付费/有限免费额度                                                        | CN                     | 有正式 API 但需商务采购，不适合插件内置                           |
| USPTO PatentsView Search API v1       | `https://search.patentsview.org/api/v1/`（patent / publication / patent_claims 等）        | 需 `X-Api-Key`（旧版 2025-05 停用，数据门户 2026-03-20 迁至 Open Data Portal 改用 ODP key） | US                     | 可用但须用户自带 key                                              |
| EPO OPS 3.2                           | `https://ops.epo.org/3.2/rest-services`（biblio / claims / abstract / CQL / INPADOC 同族） | OAuth2 Consumer Key + Secret（开发者门户免费注册）                                          | EP + INPADOC worldwide | 可用但须用户自带凭据；是 CN 检索的推荐通道                        |
| Google Patents                        | 站点内部端点 `https://patents.google.com/xhr/query?url=<编码后的查询串>`                   | 无需 key                                                                                    | 全球（含 CN）          | 非官方、形状可能变、ToS 风险，仅作零凭据兜底                      |

未发现成熟免维护的公开「专利数据库 MCP server」可作稳定依赖，故插件不引入新的
运行时依赖：核心是「归一 + 档位判定 + 检索指引」，provider 侧留给用户自带 key 或
模型侧网络工具。

### 结构化返回字段

公布号、名称、申请人、**申请日**、**公开日**、优先权日、IPC/CPC、摘要、权利要求
首项。其中申请日与公开日是「能否作有效对比文件」的决定性字段——实战检索命中多
篇高相关对比文件，但先后未核验，直接决定其可用性。

### 日期档位口径（最小机械判定，非法律判断）

| 档位           | 条件                                       | 含义             |
| -------------- | ------------------------------------------ | ---------------- |
| `prior-art`    | 对比文件申请日早于本申请申请日             | 可作有效对比文件 |
| `needs-review` | 仅公开日早于本申请申请日，申请日不早或缺失 | 需另判           |
| `later`        | 申请日与公开日均不早于本申请申请日         | 不可作对比文件   |
| `unknown`      | 缺本申请申请日或缺对比文件日期             | 档位未知         |

### 语义干扰排除

实战检索到多篇字面含「白名单/交集」但语义无关的文献（FPGA 物理层波形匹配、规则
覆盖型交集等），直接引用会误引。工具只做**字面辅助**：记录与检索词无实词交集、或
缺少名称与分类时标注提示，交人工/模型复核——工具不断言语义无关。
