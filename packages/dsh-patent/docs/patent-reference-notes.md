# 中国专利公布文本撰写参考语料（6 份样本提炼）

来源：用户提供 的 6 份 CNIPA 公布/授权文本（CN122310513A/B、CN115996222A/B、
CN121967546A、CN122021493A）的逐页视觉分析结论。用途：撰写交底书时参考公开
专利文本的结构与措辞；权利要求式表述（保护要点）的宽容校验依据。原件不入库。

## 结构（电子公布文本形态）

固定顺序：扉页（含 (57) 摘要与摘要附图）→ 权利要求书 → 说明书 → 说明书附图。
**没有独立的"说明书摘要"页**——摘要只印在扉页 (57) 栏。

授权版（B）扉页差异：(45) 授权公告日、(65) 已公布文献号、(73) 专利权人（替代
(71) 申请人）、(56) 对比文件 + 审查员。

## 页码双轨

- 页眉：左公布号｜中部分名（"权 利 要 求 书"字间空格式）｜右 "N/M 页"（部分内页码）
- 页脚：全文连续页码，扉页 = 1（自身不印），权利要求书从 2 起接续

## 段号与编号

- 说明书段号：**`[0001]` 半角方括号 + 4 位零填充**，跨小节连续到文末；粒度跟随
  自然段（可单句一段，步骤行可不带新段号）
- 权利要求编号：`1.` 阿拉伯数字+点（未见顿号式）
- 摘要：单段无段号，约 230-320 字（与 ≤300 字规范一致）

## 权利要求引用句式（真实变体，校验需宽容）

- 主干："根据权利要求N所述的……，其特征在于……"（后接逗号或冒号均见）
- 多引范围："权利要求1至8中任一项" 与 "权利要求1-3任一" 并存
- 引用名称带不带"一种"不统一
- 独权开头多数 "1.一种……"，但存在无"一种"的写法（如"1.基于C#的…方法"）
- 方法步骤编号三种并存：（1）（2）／ 步骤S1、／ S1、命名式
- 多类型组合顺序多样：方法→系统→介质；平台→方法→设备→介质
- 设备权句式含"实现**根据**权利要求X至Y中任一项所述的方法"
- 介质权三种变体：计算机程序被处理器执行时实现 / 计算机指令…使得…执行

## 措辞套路（写交底书可借鉴）

- 发明内容组织："第一方面，本发明提供了一种……"（方法/平台）、"第二方面"（系统）、
  "第三方面"（介质）；"进一步地，"引导从属方案；"本发明具备的有益效果是："
- 附图说明：逐图独立段，"图N是……的流程示意图/示意图/框架示意图；"（末图句号）
- 背景技术引证："申请公布号为CN102929756A的中国专利，公开了……"
- 说明书尾部声明："以上所述的实施例只是本发明的较佳的方案，然其并非用以限制本
  发明。……均落在本发明的保护范围内。"
- "所述"使用密度极高（术语前几乎必加）

## A/B 修改模式（公开 → 授权）

- 权利要求合并收紧：部分从权内容并入独权（独权变长）、剩余从权重编号且引用
  基准统一改为直接引用权 1、介质权引用范围跟随新编号
- 说明书、附图、发明名称、摘要逐字不变；总页数变化仅来自权利要求书

## 对校验工具的指引

权利要求编号按 `\d+\.`；段号按 `\[\d{4}\]`；引用句式宽松匹配
（"至|-"、"中任一项|任一"、引用带不带"一种"）；不对"其特征在于"后标点做硬校验。
