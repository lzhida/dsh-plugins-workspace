新增审查侧源码对账工具 `claims_evidence_check`（专利审查系列 2/5）：以权利要求为行、说明书与源码为证据的「权项-说明书-源码」三方对账引擎。模型读码取证后提交逐特征记录（权项位置 / 特征原文 / 说明书位置 / 源码锚点 / 四态判定 / 建议），工具强制证据纪律（无 `文件:行号` 锚点的判定一律拒绝输出）、检查权项覆盖完整性、识别载体归属矛盾（同一特征在权项与说明书归到不同载体）、评估从属链退守风险（引用基准并列分支 + 链上失实污染），并输出 JSON + markdown 对账矩阵与未覆盖资产清单；报告开头给出按常量 / 路径 / 枚举 / 函数名 / 层级序 / 分支数六维抽取的待核对清单（只提示该查什么，不代替判定）。四态判定：可主张 / 需改写 / 不可主张（低于 high 严重度时告警）/ 未覆盖。工具不读源码、不替模型断言；专利审查方法论 skill 的收敛纪律节同步引用该工具作为对账收口。
