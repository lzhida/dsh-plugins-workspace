新增审查侧初稿审查主工具 `draft_review_check`（专利审查系列 3/5）：复核代理师初稿并输出分级问题清单（严重 / 高 / 中 / 低 / 建议），每条含位置 / 问题 / 依据 / 建议。输入支持初稿 docx 路径（插件内含最小 zip 解析，只读 word/document.xml，无新增依赖）与摘要 / 权项书 / 说明书 / 附图文本。`focus` 裁剪检查面：`comply`（默认）/ `formal` / `prior-art` / `strategy`。机检面覆盖权项结构、说明书五部分、摘要字数与名称一致、附图标记体例与悬空图号、发明内容↔权项逐字对应、术语裸用与绝对化措辞、逐字重复度、背景技术封闭列举的效果链闭环、程序型权缺失、无源码落点特征；需要人判断的项（数值事实、图面语义、现有技术检索等）只出「待模型判断的核查清单」，不写成结论。接入 `claims_evidence_check` 的证据记录后，一并报告从属链失实污染风险。另支持两个可选入参：`disclosurePath` 读入交底书文件参与逐字重复度交叉比对，`sourceRoot` 列出源码目录文件清单（跳过依赖目录）供模型逐条读码对照——工具不读码、不替模型断言。
