流式中途失败的行为边界定稿：宿主把流式中途失败归一化为 terminal finish chunk 并派发同一失败事件（`agent/request-error`），但失败对象 `LlmFailure` 无「流已开始」信号，插件无法区分产出前与产出后——定稿四条边界（决策面 / 产出前 / 产出后 / 呈现侧）：产出后失败同样照常切换，重试请求由宿主从零重建、失败半截不进模型上下文，不存在「新模型重复已输出内容」。新增产出前 / 产出后 / 非白名单三组边界单测；协议文本与 README 补边界说明与能力缺口记录；「继续」唤醒评估落档为不采纳（理由与若将来采纳的配置形态写入 README）。无行为变更。
